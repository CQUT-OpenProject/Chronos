## 一、服务说明

1. Chronos 是一款基于渐进式 Web 应用（PWA）技术的课程表管理工具，旨在帮助用户便捷地查看、编辑与管理个人课程安排。
2. 本软件以开源形式发布，源代码托管于 GitHub（[CQUT-OpenProject/Chronos](https://github.com/CQUT-OpenProject/Chronos)），遵循 Apache License 2.0 许可协议。
3. 本软件主要功能包括但不限于：
   - 课程表的创建、编辑、切换与删除；
   - 按教学周查看课程安排；
   - 从知行理工在线系统、分享 JSON 或教务 HTML 文件导入课表；
   - 将课表导出为分享链接；
   - 主题模式与课表壁纸等个性化设置；
   - 安装为本地应用（PWA）以离线使用已缓存内容。
4. 本软件**不提供**独立的用户注册或账号体系。除知行理工在线导入功能所涉及的代理请求外，您的数据主要保存在您本人的设备浏览器中。

1. 本软件提供「知行理工」在线导入功能，允许您使用重庆理工大学统一身份认证系统（UIS）的学号与密码，经本软件服务端代理，从重庆理工大学官方课表系统获取课程数据。

3. 您理解并同意，使用知行理工在线导入功能时，您的学号及经客户端加密后的密码将被发送至本软件服务端，以完成与官方系统的认证。**本软件服务端不会在数据库或其他持久化存储中保存您的明文密码或凭据。** 详情请参阅《Chronos 隐私政策》。

## 四、数据导入、导出与本地存储

1. **导入方式：** 除知行理工在线导入外，本软件还支持通过分享 JSON 文本或上传教务 HTML 文件导入课表。上述方式均在您的设备本地完成解析，不涉及向本软件服务端发送您的教务账号密码。
2. **导出分享：** 本软件允许您将当前课表导出为分享链接（JSON 格式）。导出内容仅包含课程安排及相关学术配置信息，**不包含**您的学号、密码或任何认证凭据。
3. **本地存储：** 您确认并同意，导入或手动编辑的课表数据、主题偏好、壁纸图片及可选保存的加密凭据均存储于您设备的浏览器本地存储空间（包括 IndexedDB、localStorage 及 sessionStorage）。您可通过「关于 → 清除所有数据」删除上述本地数据。
