# 导入课表

Chronos 支持三种导入方式：知行理工在线导入、分享链接与教务系统导出的 HTML 文件。

## 知行理工（在线导入）

在应用内选择导入方式为「知行理工」，输入知行理工账号密码即可拉取课表。

- 支持选择校区；导入确认阶段可核对学期起始日等配置。
- 在线导入依赖服务端代理转发教务请求，**仅在官方 Vercel 部署上可用**；GitHub Pages 等纯静态部署不支持。
- 凭据仅用于本次拉取，不会被保存为明文（Web 端已移除凭据保存功能，见 [ADR 0017](/adr/0017-webauthn-credential-retirement)）。

## HTML 文件导入

在应用内选择导入方式为「HTML 文件」，并按照以下步骤操作：

1. 电脑端登录办事大厅
2. 进入【本科生教务管理系统】->【信息查询】->【个人课表查询】
3. 按下键盘的 `Ctrl + S` 或 `Cmd + S` 保存页面为 HTML 文件，将此文件发送到手机上
4. 在 Chronos 中选择导入方式，并选择刚才保存的 HTML 文件即可

> [!NOTE]
> 未验证其它学校的教务页面是否可解析。

## 分享链接导入

其他 Chronos 用户可以在导出页生成分享链接。打开链接后会进入 `/s` 统一分发页：

1. 页面根据链接元数据自动识别对应的导入插件（无需知道具体格式）
2. 展示课表预览与警告信息（如空课表、超大课表提示）
3. 确认后写入本地

分享编解码逻辑完全位于 `@chronos/plugin-codec-share` 插件内，宿主只做通用分发——详见 [ADR 0022](/adr/0022-deep-link-handshake)。

## 导入后的配置

- **周末列**：初始是否显示周六/周日由课程占用自动推导；之后可在课表详情中手动开关。
- **节次时间**：校区节次表由数据源插件提供，可在详情页切换；自定义修改会保存在课表的自定义元数据中。
- **覆盖当前课表**：确认导入时若选择覆盖，将替换当前活动课表；否则创建为新课表。
