# 快速开始

[English](/) | 中文

Chronos 是一个基于渐进式 Web（PWA）的课程表应用：无需安装应用商店客户端，浏览器打开即用，也可添加到主屏幕离线使用。

## 打开 Chronos

直接访问官方站点即可。若计划长期使用，建议通过浏览器的「添加到主屏幕 / 安装应用」功能将其安装为 PWA——安装后启动更快，且支持完全离线查看已导入的课表。

## 首次导入课表

首次进入应用后，从「我的」页面进入数据导入。Chronos 支持三种导入方式：

- **知行理工在线导入** —— 输入教务账号密码直接拉取（需要服务端代理，仅官方 Vercel 部署提供）
- **HTML 文件导入** —— 从电脑端教务系统保存课表页面为 HTML 后导入
- **分享链接导入** —— 打开他人分享的 `/s` 短链，一键预览并确认导入

各方式的详细操作见[导入课表](./import-sources.md)。

## 日常使用

- **查看**：主页展示当前周课表，自动高亮进行中的课程与节次。
- **管理课表**：可创建多个课表（如不同学期），在课表间切换或删除旧课表。
- **调整详情**：在课表详情中修改校区节次时间、学期起始日、周末列显示等配置。
- **主题外观**：「显示设置」提供配色主题选择；部分主题支持壁纸动态取色。
