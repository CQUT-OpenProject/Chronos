## 提交收录约定

各 ADR 头部的「关联提交」字段（`git short hash`，按时间排序）记录实现该决策的全部提交，覆盖范围自 `6c23e91f5` 起的完整重构历史。纯文案调整、依赖升级、构建产物同步及 ADR 文档自身的提交不列入；跨决策的桥接提交允许同时出现在两篇 ADR 中。
