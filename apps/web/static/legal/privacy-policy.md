# Chronos 隐私政策

**生效日期：2026 年 8 月 13 日**

CQUT-OpenProject（以下简称「我们」）深知个人信息对您的重要性。本隐私政策旨在向您说明 Chronos（以下简称「本软件」）如何收集、使用、存储和保护您的信息，以及您所享有的相关权利。

请您在使用本软件前仔细阅读本政策。**您安装、访问或使用本软件，即视为您已阅读、理解并同意本政策。** 如您不同意本政策任何内容，请立即停止使用本软件。

---

## 一、适用范围

本政策适用于您通过浏览器或已安装的 PWA 形式使用 Chronos 时，我们及本软件对您信息的处理活动。

本政策不适用于：

- 重庆理工大学知行理工及其官方系统（统一身份认证、课表服务等）对您信息的处理；
- 您通过本软件访问的第三方网站或服务；
- 您自行部署的本软件实例（自行部署时，运营方应另行制定隐私政策）。

## 二、我们收集的信息

### 2.1 您主动提供或生成的信息

| 信息类型 | 收集场景 | 存储位置 |
|----------|----------|----------|
| 课表与课程数据 | 手动编辑、导入（知行理工 / JSON / HTML） | 设备本地（IndexedDB） |
| 学术配置 | 学期起始日、教学周范围、校区节次时间等 | 设备本地（IndexedDB） |
| 外观偏好 | 主题模式（亮色 / 暗色 / 跟随系统）、配色方案（默认 / 壁纸抽色 / 随机）、课表布局 | 设备本地（localStorage） |
| 课表壁纸 | 上传自定义图片 | 设备本地（IndexedDB） |
| 导入预览数据 | 导入流程中的临时预览 | 设备本地（sessionStorage，关闭标签页后清除） |

当您选择「壁纸」配色方案时，本软件会在您的设备本地从壁纸图片提取配色，**不会将壁纸上传至我们的服务器**。

### 2.2 知行理工在线导入相关信息

当您使用「知行理工」在线导入功能时，可能涉及以下信息：

| 信息类型 | 说明 |
|----------|------|
| 学号（账号） | 用于向重庆理工大学统一身份认证系统发起登录 |
| 密码 | 仅在您输入时存在于浏览器内存；传输前经客户端 RSA 加密 |
| 课表数据 | 从官方课表系统获取的课程名称、教师、地点、上课时间等 |
| 校区信息 | 您在官方系统中的校区偏好及对应节次时间表 |

### 2.3 服务端处理的信息

本软件服务端（用于代理知行理工在线导入）在单次请求期间可能接触以下信息：

| 信息类型 | 说明 | 是否持久化存储 |
|----------|------|----------------|
| 学号 | 用于认证 | **否** |
| 加密后的密码 | 客户端 RSA 加密后的密文，用于向官方系统认证 | **否** |
| 客户端 IP 地址 | 用于请求频率限制（防滥用） | **否**（仅内存计数，不写入数据库） |

### 2.4 使用情况统计（仅官方托管版）

我们提供的官方托管版（已配置分析服务密钥的生产环境）会收集**匿名化的使用情况统计**，用于了解功能使用情况、改进本软件。该统计**不**包含您的课表内容、学号、密码、壁纸或任何认证凭据。

| 信息类型 | 说明 | 存储位置 |
|----------|------|----------|
| 功能使用事件 | 如引导流程、导入/导出、课表操作、主题/配色/布局变更、壁纸设置、PWA 安装与更新、清除数据等 | 发送至 PostHog（欧盟区域云） |
| 事件属性 | 如操作类型、来源、步骤、成功/失败等枚举值 | 同上 |
| 页面浏览 | 页面路径变更（如路由切换） | 同上 |
| 匿名标识符 | 由分析 SDK 生成的 distinct_id，用于区分不同访问会话 | 设备本地（localStorage）及 PostHog |
| 技术信息 | 浏览器类型、操作系统、屏幕尺寸等 SDK 自动附加的技术字段 | PostHog |

**启用条件：** 仅在生产环境且已配置 `PUBLIC_POSTHOG_KEY` 时启用。本地开发环境、GitHub Pages 静态版及未配置分析密钥的自行部署实例**不会**启用上述统计，相关代码在构建期被剔除。

**隐私配置：** 我们已关闭自动元素捕获（autocapture）与会话录制（session recording），仅上报本软件主动触发的统计事件及页面浏览。

**第三方服务：** 统计数据由 [PostHog](https://posthog.com/) 提供托管与分析，数据可能传输至其欧盟区域服务器（`eu.i.posthog.com`）。PostHog 可能根据其项目设置接收客户端 IP 地址等技术信息，具体处理规则请参阅 PostHog 隐私政策。

### 2.5 我们不收集的信息

本软件**不**收集以下信息：

- 独立注册账号或用于广告投放的用户画像；
- 设备通讯录、相册（壁纸由您主动选择）、地理位置、麦克风、摄像头等权限数据；
- 明文形式的密码或认证凭据；
- 使用情况统计中的课表正文、课程名称、教师、地点或认证凭据。

## 三、知行理工凭据处理（重要）

本节专门说明您在使用知行理工在线导入时，本软件对学号与密码的处理方式。

### 3.1 本软件不保存明文密码

**无论任何情况下，本软件均不会在设备本地或服务端以明文形式保存您的密码。**

具体而言：

1. **输入阶段：** 密码仅存在于浏览器运行时的内存中，用于完成当次导入操作。
2. **传输阶段：** 密码在离开您的设备之前，由本软件客户端使用重庆理工大学官方系统所采用的 RSA 公钥进行加密。发送至本软件服务端的仅为加密后的密文（`encryptedPassword`），而非明文密码。
3. **服务端阶段：** 本软件服务端（`/api/plugins/source-cqut/preview` 接口）在内存中处理您的学号与加密密码，代您向重庆理工大学官方系统完成认证并获取课表数据。**请求处理完成后，服务端不会将学号、密码（无论明文或密文）或会话凭据写入任何数据库、文件或持久化存储。**
4. **导入结果：** 获取的课表数据返回至您的浏览器后，仅课程安排等教务信息被保存至设备本地 IndexedDB，**不包含您的密码。**

### 3.2 可选的「保存凭据」功能

本软件提供可选的凭据保存功能，以便您下次导入时无需重新输入密码。该功能的行为因设备能力而异：

| 模式 | 触发条件 | 存储内容 | 安全机制 |
|------|----------|----------|----------|
| 加密保存 | 设备支持 WebAuthn PRF | 学号 + 经 AES-256-GCM 加密的密码密文 | 加密密钥由设备生物识别或 PIN 通过 WebAuthn PRF 派生；未通过验证无法解密 |
| 仅保存学号 | 设备不支持 WebAuthn PRF | 学号（明文） | 密码不会被保存，每次导入需重新输入 |

**重要提示：**

- 即使您选择保存凭据，密码也仅以加密密文形式存储于您设备的 `localStorage` 中，**绝非明文**；
- 加密凭据仅保存在您的设备上，不会上传至本软件服务端；
- 您可随时在导入页面点击「清除已保存凭据」，或通过「关于 → 清除所有数据」删除所有本地存储信息（含加密凭据与学号）。

### 3.3 第三方系统

向重庆理工大学官方系统（`uis.cqut.edu.cn`、`timetable-cfc.cqut.edu.cn`）发起的认证与数据请求，由上述系统的运营方依照其自身的隐私政策与用户协议处理。我们建议您同时查阅相关官方说明。

## 五、信息的存储与安全

### 5.1 本地存储

您的课表数据及偏好设置主要存储于您设备的浏览器中：

- **IndexedDB：** 课表、课程、壁纸图片；
- **localStorage：** 主题模式、配色方案、课表布局、可选加密凭据或学号；官方托管版启用统计时，分析 SDK 生成的匿名标识符亦存于此；
- **sessionStorage：** 导入流程中的临时预览数据。

上述数据不会自动同步至我们的服务器。清除浏览器数据、卸载 PWA 或执行「清除所有数据」将导致本地信息被删除且通常不可恢复。

### 5.2 服务端

本软件服务端部署于 Vercel 平台，仅提供知行理工在线导入的代理接口。我们不在应用层持久化存储您的个人信息。请求处理过程中的会话状态（如 Cookie）仅存在于单次请求的内存中。

### 5.3 安全措施

我们采取以下措施保护您的信息安全：

- 客户端密码 RSA 加密后再传输；
- 可选凭据采用 WebAuthn PRF + AES-GCM 加密存储；
- 服务端接口实施 IP 频率限制；
- 全站 HTTPS 传输加密；
- 使用情况统计关闭自动元素捕获与会话录制，且不上报课表内容与凭据。

请您理解，互联网环境并非绝对安全。我们建议您妥善保管设备、及时更新浏览器，并谨慎使用公共设备访问本软件。

### 5.4 托管基础设施

本软件托管于 Vercel 等第三方云平台。这些平台可能在基础设施层面记录访问日志（如 IP 地址、请求时间等），该等记录由平台方依照其隐私政策管理，不在本软件应用层的控制范围内。

官方托管版的使用情况统计由 PostHog 托管，数据可能传输至其欧盟区域服务器。PostHog 作为独立第三方，其数据处理规则不受本软件应用层直接控制。

## 六、信息的共享与披露

我们不会出售您的个人信息。除以下情形外，我们不会向第三方共享您的个人信息：

1. **重庆理工大学官方系统：** 为完成知行理工在线导入，您的学号与加密密码将按官方接口要求发送至重庆理工大学统一身份认证及课表系统；
2. **PostHog（仅官方托管版）：** 为统计功能使用情况，匿名化的使用事件及技术信息将发送至 PostHog 欧盟区域云进行分析；
3. **法律要求：** 依据法律法规、诉讼、仲裁或政府主管部门的强制性要求；
4. **保护权益：** 为保护我们、您或其他用户的合法权益所合理必要的情形。

通过「分享课程表」功能生成的链接仅包含课表数据，**不包含学号、密码或任何认证凭据**。请您在分享时自行判断链接接收方是否可信。

您对自己的信息享有以下权利：

| 权利 | 行使方式 |
|------|----------|
| 查阅与编辑 | 在课表管理、课程设置等页面直接查看和修改 |

| 停止使用 | 卸载 PWA、清除浏览器数据或不再访问本软件 |

**关于已发送的统计数据：** 清除本地数据无法撤回已发送至 PostHog 的匿名事件。如您希望就此类数据提出疑问或行使相关权利，请通过本政策末尾的联系方式与我们联系。

## 八、未成年人保护

本软件主要面向在校学生。若您为未满 18 周岁的未成年人，请在监护人的陪同与同意下使用本软件，并由监护人指导您阅读本政策。

我们不会主动收集未成年人的个人信息。若监护人发现我们在未获同意的情况下处理了未成年人的信息，请通过联系方式告知我们，我们将尽快删除相关信息。
